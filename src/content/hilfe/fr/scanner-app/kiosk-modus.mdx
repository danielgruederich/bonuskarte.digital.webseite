Avec le mode kiosque de l'application scanner, vous simplifiez vos opérations, évitez les scans en double et distribuez les points de fidélité automatiquement — directement depuis votre ordinateur, votre tablette ou votre smartphone.

## Où trouver le mode kiosque ?

Le mode kiosque se trouve en haut à droite, dans le menu hamburger, sous votre profil de manager.

<Callout type="info">
L'application scanner fonctionne dans le navigateur, sans installation. Vous pouvez toutefois l'enregistrer sur l'écran d'accueil de votre appareil pour y accéder plus rapidement.
</Callout>

<Callout type="tipp">
Chaque manager doit se connecter avec ses propres identifiants.
</Callout>

## Configurer le mode kiosque

Dans le mode kiosque, vous définissez les règles de distribution automatique des tampons ou des points. Vous réglez également le temps qui doit s'écouler entre deux scans — par exemple 10 ou 20 secondes.

Vous évitez ainsi les transactions en double lorsqu'une même carte est scannée à quelques instants d'intervalle.

Dans la liste, vous voyez toutes les cartes de votre compte. Vous pouvez activer le mode kiosque pour une seule carte ou pour toutes les cartes à la fois.

<Callout type="info">
Si une carte ne peut pas être activée, c'est que ce type de carte n'est pas pris en charge par le mode kiosque.
</Callout>

## Comment lancer le mode kiosque

1. Cliquez sur **Démarrer** — l'appareil photo s'active
2. Scannez la carte de votre client
3. La transaction s'exécute automatiquement

Dans les dernières transactions, vous constatez que la visite a bien été enregistrée.

## Points importants

<Callout type="warnung">
Pour la configuration, vous avez besoin des identifiants du compte principal.
</Callout>

<Callout type="info">
En mode kiosque, aucune note ne peut être ajoutée à la transaction.
</Callout>

<Callout type="warnung">
Si l'appareil est éteint ou déconnecté, le mode kiosque se désactive et doit être réactivé manuellement.
</Callout>

Avec le mode kiosque, votre processus de fidélité devient plus rapide, plus simple et plus fiable.
