## 1. Was ist bonuskarte.digital?

B2B-Lead-Gen-Angebot für **digitale Stempel-/Kundenkarten** im Apple- & Google-Wallet.
Es ist ein **White-Label-Wiederverkauf der Boomerangme-Plattform** unter eigener Marke.
Positionierung: hyper-lokal (Landing Pages pro Stadt × Stadtteil × Branche), Hook
**„90 Tage kostenlos testen"**.

**Kern-Nutzenversprechen:** Mehr Stammkunden, mehr Umsatz. Die Kundenkarte liegt direkt im
Smartphone-Wallet — **kein App-Download, keine Registrierung, kein Aufwand für den Betrieb.**

---

## 2. Produkt & USP

- **Digitale Karte in Apple Wallet & Google Wallet** — auf jedem Smartphone vorinstalliert, kein Download.
- **Sofort erlebbar:** Interessent kann auf der Website in Sekunden eine **echte funktionierende Demo-Karte** erzeugen (nicht nur ein Kontaktformular).
- **Live in unter 24 Stunden**, Einrichtung wird übernommen (Kunde liefert nur Logo/Farbe/Belohnung).
- **DSGVO-konform**, monatlich kündbar, keine Einrichtungsgebühr, kein automatischer Vertragsübergang nach der Testphase.
- **Verhaltenspsychologische Hooks** in der Copy: Zeigarnik-Effekt („halbvolle Karte"), „Nur noch X bis gratis", Completion Motivation.

## 4. Feature-Set (White-Label Boomerangme — was tatsächlich beworben wird)

**Karten & Wallet:** 7 Kartentypen (Stempel-, 10er-, Coupon, Gutschein, Mitglieds-, Cashback-, Punktekarte), Apple/Google Wallet, eigenes Branding, konfigurierbares Anmeldeformular, Happy-Hour-Regeln, Tages-Stempellimit.

**Push-Nachrichten:** unbegrenzt inklusive, **Geo-Push** (~100 m Nähe, iPhone), Push-Automation (Geburtstag/Abwesenheit/Termin), Transaktions-Push, Verfalls-Erinnerung.

**Bewertungen & Empfehlungen:** automatisches Feedback nach Besuch, Google-Bewertungen sammeln, Empfehlungsprogramm (Kunden werben Kunden per Link).

**Automatisierung & KI:** Automations-Baukasten (Trigger→Bedingung→Aktion), KI-Marketing-Assistent, automatische Berichte per Mail.

**Statistiken:** Live-Dashboard (Besuche, aktive Karten, Wiederkehr-Rate, Feedback, Empfehlungen), Kundenprofile + Filter (CSV Im-/Export), Segmente & gezielte Aktionen.

**Team & Betrieb:** Scanner-App im Browser (keine Hardware), Mitarbeiter-Zugänge, Kiosk-Modus, Kundensuche ohne Scan, Stempel-Korrektur, 16 Sprachen.

**Integrationen & Enterprise:** Multi-Standort-Dashboard, API & Webhooks, Zapier/Make (5.000+ Tools), echtes White-Label mit eigener Domain.

## 8. Implementierte Sales Funnels

### 🟢 A — Self-Demo-Karte („Instant Wallet-Karte") — HAUPTFUNNEL
Interessent bekommt **sofort eine echte, funktionierende Wallet-Karte**.
Landingpage → Formular (`LeadForm`) → Backend → Boomerang legt Kunde + Demo-Karte an → gibt
Apple-/Google-Wallet-Install-Links + QR zurück. Scharf für 10 Nischen.
Döner-Variante mit vereinfachtem Ein-Feld-Formular.

### 🟢 B — Terminbuchung („Kostenloses 24-h-Setup")
`/termin` (Trafft `termin.bonuskarte.digital/15min`) bzw. SimplyMeet.me → nach Buchung `/danke`.
`/danke` stark ausgebaut: personalisiert (Name/Termin), Buchungsdetails, Foto + Zitat von Daniel,
„Was passiert als Nächstes", 3 Bonus-Leitfäden, Testimonial, WhatsApp-Weiterempfehlung.
Feuert `booking_confirmed` (GA4) + Pabbly-Webhook.

### 🟢 C — Lead-Magnet / E-Book („Leitfaden-Download")
Leitfaden-Seiten → `EbookLeadForm` (Name + Handy + optional Instagram) → Salesflare + Telegram +
Sheets + **MailerCloud-Bestätigungsmail mit PDF** → Gated Download. 3 PDFs vorhanden.

### 🟢 D — Gründer-Angebot (Lifetime 100 €)
`koeln/gruender.astro`, `source=gruender`, CRM-Tags `gruender-100` / `lifetime-100eur`. Eigener Deal-Track.

### 🟢 E — Walk-in / iPad (Offline → Digital)
`koeln/walkin.astro`, `source=gruender_walkin`, noindex, nischenunabhängig. Vor-Ort-Anmeldung am Tablet.

### 🟢 F — Chat-Agent (Zipchat, 24/7)
Site-weit eingebettet, fängt Inbound-Leads. Auf `/preise` zusätzlicher „Mit Agent chatten"-CTA.

### 🟢 G — WhatsApp-Direktkanal
`wa.me/491705594140` durchgängig als CTA. Bei **jedem** Lead baut der Telegram-Alert automatisch
einen fertigen WhatsApp-Antwortlink mit vorformuliertem Text → Follow-up in einem Tap.

### 🟡 H — A/B-Test-Startseite (v2)
`v2.astro` „Bestellzettel"-Design (Orange), `source='v2'`, canonical → `/`, nicht in Sitemap.

### 🟡 I — International (vorbereitet)
FR (Paris): volle Struktur, aber `mode: 'lead'` = **lead-only, keine Karte** (nur Salesflare).
EN: Seiten vorhanden (index, pricing, features, cards, help).

## 9. Lead-Verarbeitung (MarTech-Stack hinter dem Formular)

Jeder Lead löst im Backend einen **Fan-out** aus (fire-and-forget, blockiert nie die Antwort):

| System | Rolle |
|---|---|
| **Salesflare** | CRM — Account + Kontakt + Opportunity, getaggt nach Stadt/Nische/UTM/Funnel |
| **Telegram** | Sofort-Alert an Daniel mit fertigem WhatsApp-Antwortlink |
| **Google Sheets** | Roh-Log aller Leads |
| **MailerCloud** | Transaktionsmail (E-Book-Bestätigung) |
| **Pabbly Connect** | Buchungsbestätigungs-Automation (SimplyMeet.me → /danke) |
| **Boomerang** (digitalwallet.cards) | Karten-Plattform (Kunde + Karte anlegen) |

**Wichtig:** Salesflare läuft VOR Boomerang → ein Lead geht nie verloren, selbst wenn die
Karten-Erstellung scheitert.

## 10. Tracking / Attribution / Messplan

- **GA4 + Google Ads Conversion-Tag.**
- **Funnel-Messplan (Events):** `page_view → demo_card_view → signup_form_start → niche_selected → signup_submit_attempt → signup_submit (Conversion + Ads-Tag) → demo_card_created`; parallel `booking_confirmed`, `chatbot_open`, `whatsapp_clicked`, `cta_clicked`, `wallet_install_clicked`; Diagnose `signup_submit_error`.
- **UTM-Capture** durchgängig → fließt in Salesflare-Tags UND wird an alle Wallet-Install-Links angehängt (Attribution bis zur installierten Karte).
- **Funnel-Trennung** über Felder `source` / `mode` / `city` / `niche` / `booking_type`.

## 15. Tech-Stack (Kurzreferenz)

- **Framework:** Astro + React (Islands) + Tailwind CSS, Static Site Build.
- **Formular-Backend:** `POST /api/submit.php` (PHP) → Boomerang + Salesflare + Telegram + Sheets + MailerCloud.
- **Deploy:** GitHub Actions → FTP/rsync auf Starthost (StackCP), automatisch bei Push auf `main`.
- **Secrets:** außerhalb des Webroots (`bonuskarte-secrets.php`), nie im (öffentlichen) Repo.
